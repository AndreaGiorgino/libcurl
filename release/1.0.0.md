## ABI

### Methods

the `methods` enum implements the following HTTP methods:

- `DELETE`
- `GET`
- `HEAD`
- `OPTIONS`
- `PATCH`
- `POST`
- `PUT`
- `TRACE`

> Use `getMethodName` for the string representation

### Headers

The `headers` enum implements the majority of the standard headers (look at
`headers.hxx` for all of them)

> Use `getHeaderName` for the string representation, not standard headers are
> represented as "Not-Standard-<value>"

### Status codes

The `status_codes` enum implements the majority of the standard status codes
(look at `status_codes.hxx` for all of them)

> Use `getStatusCodeName` for the string representation, not standard status
> codes are represented as "Not Standard - <value>"

### Request

The `request` class implements the following members:

- `url`
- `method`
- `headers`
- `parameters`
- `postFields`

### Response

The `response` class implements the following members:

- `url`
- `statusCode`
- `headers`
- `body`

### curl

The `curl` function returns a future which allow the consumer to handle the
synchronous state as they need
